# Themes

Topics that B1 tasks draw on. Pick one per session; avoid a theme used in the last three log lines.
"File" is the vocabulary sheet in `.claude/skills/fle-vocabulary/references/` when one exists. For a theme
without a file, `fle-vocabulary` builds the lesson on the spot and can save it afterwards.
