# B1 grammar checklist

Our own list of the points a B1 candidate needs, roughly in order of payoff. "Topic" is the level-2 id in
`reference/topics.md` (prefix `morphosyntaxe/`). Every point has a file in `fle-grammar`; a new point is taught from the four-part
structure there and gets a file when it becomes a weak point.

## Sentence basics
| Point | Topic |
|---|---|
| Élision and contracted articles (qu'il, d'apprendre, au, du) | elision |
| Agreement of determiners, adjectives and participles; place of the adjective | accords |
| Subject-verb agreement (on, tout le monde, la plupart) | accord-verbe |
| Negation (ne…pas, plus, jamais, rien, personne, pas encore, que; pas de) | negation |
| C'est or il est; il y a | cest-il-est |
| Possessives and demonstratives (son/sa/ses, leur/leurs, le mien, celui qui, celui de) | possessifs-demonstratifs |
| Question forms (est-ce que, inversion, quel, lequel; qui, que, quoi, qu'est-ce qui/que; preposition + qui/quoi) | questions |
| Indefinites (tout/tous/toutes, quelques, plusieurs, chaque, quelque chose de + adjective) | indefinis |
| Adverbs (-ment, bon/bien, mauvais/mal, rapide/vite; place, also in compound tenses) | adverbes |

## Verbs, tenses and moods
| Point | Topic |
|---|---|
| Present tense of irregular verbs (two and three stems: prendre, venir, pouvoir, devoir) | present |
| Pronominal verbs (reflexive, reciprocal, place of the pronoun, agreement) | pronominaux |
| Passé composé, imparfait, plus-que-parfait in a story | temps-du-recit |
| Futur simple and futur proche; quand + futur; venir de, être en train de, être sur le point de | futur |
| Conditionnel présent: politeness, advice, wish | conditionnel |
| Hypothesis with si (présent/futur, imparfait/conditionnel, plus-que-parfait/conditionnel passé) | hypothese |
| Subjonctif présent after il faut que, vouloir que, pour que, bien que | subjonctif |
| Impératif, with pronouns | imperatif |
| Gérondif (en travaillant) | gerondif |
| Passive voice | passif |
| Reported speech in the present and past | discours-rapporte |

## Pronouns and linking
| Point | Topic |
|---|---|
| Object pronouns, y, en, and their place | pronoms |
| Relative pronouns qui, que, où, dont; ce qui, ce que | relatifs |
| Verb + preposition (penser à, avoir besoin de, demander à qqn de) | prepositions |
| Comparison and superlative; mieux and meilleur | comparaison |
| Expressing cause, consequence, purpose, opposition, concession | see `coherence/connecteurs` |
| Time expressions (depuis, il y a, pendant, pour, dans, en, ça fait … que; avant de + infinitive, après avoir/être + participle) | expressions-de-temps |
| Articles: partitive, and de after quantity or negation | articles |
